# 全量采集跑法（223 个国家/地区）

三国（CN / FR / US）是手工样板，扩到全量靠脚本，分阶段跑、断点续跑、失败不中断。
**所有命令都在仓库根目录执行**（`E:\workbuddy\atlas-mundi`）。

---

## 0. 先决条件

```bash
# 依赖（edge-tts 用于语音，Pillow 用于压图；其余都是标准库）
pip install edge-tts pillow

# 代理：脚本读环境变量，也可以直接传参
set HTTPS_PROXY=http://127.0.0.1:7890
# 或在命令后加 --proxy http://127.0.0.1:7890

# 大模型阶段需要（只跑采集可以不给）
set DEEPSEEK_API_KEY=sk-xxxx
```

先体检一下网络（四个域名都要通）：

```bash
python scripts/collect.py CN --check
```

## 1. 阶段一：ISO → Wikidata QID

```bash
python scripts/resolve_ids.py                 # 全量，约 8~15 分钟
python scripts/resolve_ids.py --limit 20      # 先试 20 个
python scripts/resolve_ids.py --report        # 随时看进度 / 差哪些
```

产物 `data/_ids.json`：`{"JP": {"qid": "Q17", ...}, "_langs": {"Q5287": {"c1": "ja"}}}`

**校验方式**：候选实体的 P297（ISO 3166-1 alpha-2）必须等于目标 ISO，否则换英文名再搜。
仍失败的会进 `data/_ids_unresolved.json`，可以手工补：

```bash
python scripts/resolve_ids.py --set XK=Q1246
```

> 为什么不用 SPARQL：部分代理下它会返回 200 + 空结果，极难排查。这里走
> `wbsearchentities` + `wbgetentities`（批量取 claims），一次请求覆盖 5~6 个候选。

## 2. 阶段二：采集正文 / 图片 / 语言 / 坐标

```bash
python scripts/collect_all.py --stage collect --limit 5    # 先跑 5 个看质量
python scripts/collect_all.py --stage collect              # 全量，约 3~6 小时
```

每个国家产出：

| 字段 | 来源 |
| --- | --- |
| qid / iso / 首都 / 大洲 / 坐标 / 语言（含 BCP47 码） | Wikidata |
| summary_text（中文导语，300 字量级） | 中文维基 `extracts` |
| landmark_images（1~3 张，带授权与英文图注） | Commons（P18 或正文配图） |
| geometry（可选，`--geo`） | Natural Earth 50m |

采集完立刻压图（`--no-optimize-inline` 可关掉，最后统一跑 `images` 阶段）。

**断点续跑**：默认跳过「已有摘要且有图」的国家；`--force` 才重采。
进度写在 `logs/collect_all.jsonl`，每个国家的完整输出在 `logs/run_collect_*.log`。

## 2b. 阶段二点五：地标图（模型点名 + Commons 实搜）

`collect.py` 只拿得到 Wikidata 的 **P18 代表图**，每国一张，而且经常不是地标：
日本拿到"2003 年 5 月日本卫星影像"，美国拿到 UNOCHA 的定位地图。这不能当详情页主图。

三国那套好看的地标图是人工往 `data/landmarks.json` 写检索词换来的。223 国不可能手写，
但也不能靠关键词瞎猜。分两级：

```bash
python scripts/build_landmarks.py --limit 5   # 模型给每国列 6 处地标（zh / kw / must）
python scripts/fill_images.py --all           # 按 kw 去 Commons 搜，文件名必须含 must
```

`fill_images.py` 的硬性筛选（不满足直接淘汰）：

| 条件 | 原因 |
| --- | --- |
| 文件名含 `must` | 搜 "Eiffel Tower" 会返回塔底仰拍、战神广场鸟瞰 |
| 宽度 ≥ 900px | 再小在详情面板里会糊 |
| 宽高比 ≤ 2.2 | 5:1 的全景长条会把主体压成一条 |
| 非地图/旗帜/徽章 | 靠文件名规则过滤 |

**模型编造的地标会被自动淘汰**（Commons 搜不到）。实测日本 6 处里成功 5 处
（富士山 / 伏见稻荷 / 晴空塔 / 广岛原爆慰灵碑 / 姬路城），漏掉的是东大寺
（候选全被宽高比筛掉）。宁可 5 张真的，不要 6 张凑数。

产物写回 `landmark_images`，带 `caption_zh`（中文图注）—— 采集阶段那批图没有图注，
详情页会显示空白。

## 3. 阶段三：大模型（特征 / 摘要 / 成文 / 图注 / 质检 / 问答）

```bash
python scripts/collect_all.py --stage llm --limit 10
python scripts/collect_all.py --stage llm
```

每国约 6~9 次调用（`facets / summary / compose / captions×3 / audit / qa`）。
`compose` 是新加的：中法美的「历史与民俗」是人工稿，全量只能让模型按
「只使用给定材料」的硬约束成文，产出存 `data/_llm/{iso}.compose.json` 供抽查。

只重跑某一类：

```bash
python scripts/llm_tasks.py --run JP --only compose --apply
```

调用账本在 `logs/llm_calls.jsonl`（不记正文），`python scripts/llm.py --stats` 看总量。

## 4. 阶段四：语音

```bash
python scripts/speech_all.py --voices ja      # 看某语言有哪些音色
python scripts/collect_all.py --stage speech
```

规则：

- 只给**官方语言**做，小国（人口 < 1000 万）只做一条 —— 与前端卡片一致；
- 句子由大模型写（5~6 秒的口语欢迎语 + 简体中文译文），不是干念国名；
- 音色按 Locale 自动匹配，查不到音色的语种**跳过并留痕**（如夏威夷语、布列塔尼语），
  不用邻近语种硬读。

## 8. 已知限制（别期待和三国一模一样）

1. **图片是自动挑的**。三国用的是人工挑选的地标（埃菲尔铁塔、长城），
   全量走 P18 代表图 / 正文配图，可能挑到市政厅、街景，甚至被过滤成 0 张。
   想提升只有两条路：给重点国家补 `data/landmarks.json` 关键词，或人工换图。
2. **摘要长度不均**。小国维基条目只有一两句，LLM 精炼后会低于 300 字。
3. **民俗成文是模型稿**。有 evidence 可核，但没有人工稿的质感；
   三国的人工稿不要被覆盖（`compose` 只在 `custom_text` 为空时写，或显式 `--force`）。
4. **语音语种覆盖有限**。Edge TTS 约 70 个语种，冷门语种跳过。
5. **球面国界**只有三国是精细几何，其余国家点开时才按需画（`geo/c*.json`）。

## 9. 常见报错

**`UnicodeEncodeError: 'gbk' codec can't encode character '\u2717'`**

2026-10-28 那次"五国全失败"就是它：脚本在 cp936 终端里打印 `✓/✗` 直接抛异常，
看起来像采集失败，其实连抓取都没开始。现在所有脚本都做了两件事：
非 ASCII 符号换成 `[ok]`/`[x]`，并且 `sys.stdout.reconfigure(errors="replace")` 兜底。

**`SSL handshake timed out` / 连接失败，但浏览器能打开维基**

Python 的 urllib **不读 Windows 系统代理**（Clash/v2rayN 改的是注册表），只认
`HTTP_PROXY / HTTPS_PROXY`。`scripts/netcheck.py` 会自动探测：环境变量 → 注册表 →
常见端口（7897/7890/10809…），每个候选都真抓一次维基才算数。所有入口都接了；
要手工指定就加 `--proxy http://127.0.0.1:7897`。

**重复 ISO 覆盖**：Natural Earth 里 AU 有三个要素（Australia / Indian Ocean Ter. /
Ashmore and Cartier），后写的会把澳大利亚覆盖成"澳屬印度洋領地"（人口 2387）。
`build_countries.py` / `build_labels.py` 现在同 ISO 只留人口最多的那个。


| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 四个域名全 0 可达 | 代理没开 / 规则没覆盖 wikimedia | 开代理，或 `--proxy` 指定 |
| `没有 XX 的 QID 映射` | `_ids.json` 里缺这条 | `resolve_ids.py --set XX=Qxxx` |
| `HTTP 429` | 请求太密 | 加大 `--sleep`，脚本本身有退避重试 |
| 语音全跳过 | 语言码解析不到 / 无音色 | `speech_all.py --voices <code>` 查 |
| `upload 失败 401` | AK/SK 过期 | 换子用户密钥 |
